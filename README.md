Требования к типам данных
1. Перечисления (enum)
Создайте перечисления:

HeroClass — Warrior, Mage, Healer.

ItemType — Weapon, Armor, Potion.

StatusEffect — None, Blessed, Cursed, Poisoned. Используется при создании героя: игрок выбирает, какой статусный эффект назначить герою (или None).

2. Битовые поля
Структура StatusFlags с битовыми полями (все unsigned int, ширина 1 бит):

blessed — благословлён (удвоение урона)

cursed — проклят (урон вдвое меньше)

poisoned — отравлен (3 HP урона в начале хода)

3. Объединение (union)
Структуры характеристик:

WeaponStats: int damage, int durability, bool twoHanded.

ArmorStats: int defense, int durability, bool magical.

PotionStats: int healAmount — объём лечения HP, int manaAmount — восстановление MP.

Объединение ItemProperties содержит три поля этих типов. Активное поле определяется ItemType предмета.

4. Структуры
Item — предмет:

string name

ItemType type

int weight

int value

ItemProperties props

Hero — герой:

string name

HeroClass heroClass

int level

int hp, int maxHp

int mp, int maxMp

StatusFlags status — статусные эффекты (битовые поля)

Item* equipment — указатель на динамический массив из 4 слотов (выделяется через new)

int equippedCount

Enemy — враг (упрощённая структура):

string name

int hp

int damage

5. Массивы, vector и array
array<Item, 16> — инвентарь. Свободный слот помечается пустым именем ("").

vector<Hero> — отряд героев.

Динамический массив Enemy* — список врагов. Выделяется через new[], расширяется вручную, освобождается через delete[].

Что должно быть реализовано
Вся логика — в main(), через цикл с главным меню и вложенными меню. Используйте switch и if/else для навигации.

Главное меню
1. Управление отрядом
Добавить героя — ввод имени, выбор класса (1 — Warrior, 2 — Mage, 3 — Healer), ввод уровня. Затем выбор статусного эффекта (0 — None, 1 — Blessed, 2 — Cursed, 3 — Poisoned) — эффект сразу устанавливается в битовые поля героя. HP и MP рассчитываются от класса и уровня:

Warrior: maxHp = 100 + level * 20, maxMp = 10 + level * 2

Mage: maxHp = 50 + level * 8, maxMp = 100 + level * 25

Healer: maxHp = 60 + level * 10, maxMp = 80 + level * 20

При создании героя выделите equipment через new Item[4], заполните слоты пустыми предметами, equippedCount = 0.

Удалить героя — по индексу. Перед удалением освободите equipment через delete[].

Показать всех героев — имя, класс (строкой), уровень, HP/MP, активные статусные эффекты (прочитать битовые поля и вывести названия активных).

2. Управление инвентарём
Добавить предмет — ввод имени, выбор типа (1 — Weapon, 2 — Armor, 3 — Potion), веса, стоимости. Затем через switch по ItemType — ввод характеристик для активного поля объединения:

Weapon — урон, прочность, двуручность (0/1)

Armor — защита, прочность, магическая ли (0/1)

Potion — объём лечения HP, восстановление MP

Предмет помещается в первый свободный слот array. Если свободных нет — сообщение об ошибке.

Удалить предмет — по индексу слота. Слот очищается (name = "").

Показать инвентарь — таблица всех предметов с полной информацией, включая характеристики из объединения (через switch по типу).

3. Экипировка героев
Надеть предмет — выбрать героя (по индексу) и предмет из инвентаря (по индексу). Предмет копируется в следующий свободный слот equipment героя, слот инвентаря очищается. Если все 4 слота заняты — ошибка.

Снять предмет — выбрать героя и номер слота экипировки. Предмет возвращается в первый свободный слот инвентаря, слот экипировки очищается.

Показать экипировку героя — выбрать героя, вывести список надетых предметов.

4. Управление врагами
Добавить врага — имя, HP, урон. Динамический массив расширяется: new Enemy[newSize] → копирование старых данных → delete[] старый → переназначение указателя. Для ввода имени врага используйте char nameBuffer[100] (C-строка), затем создайте string через конструктор — это демонстрирует работу с C-строками из главы 4.

Удалить врага — по индексу. Массив сжимается аналогично.

Показать всех врагов — список с параметрами.

5. Симуляция битвы
Вывести списки героев и врагов.

Битва пошаговая, в цикле. На каждом ходу:

Статусные эффекты — для каждого живого героя: если poisoned — снять 3 HP. Если cursed — урон на этом ходу уменьшается вдвое. Если blessed — урон удваивается. Эффекты действуют весь бой (не снимаются после одного хода).

Ход героев — каждый живой герой выбирает цель (индекс врага) и может использовать способность за ману:

Warrior — способность «Боевой клич» (стоит 20 MP): урон ×1.5. Базовый урон — 15. Если способности нет — урон = 15 + урон оружия.

Mage — способность «Чароплёт» (стоит 40 MP): урон ×3. Базовый урон — 8. Если способности нет — урон = 8 + урон оружия.

Healer — способность «Лечение» (стоит 40 MP): восстанавливает HP выбранному союзнику на значение своего базового урона (6 + урон оружия, если надето). Цель — герой из отряда (не враг).

Пользователь перед атакой выбирает: использовать способность (если хватает MP) или атаковать обычным ударом. Если маны недостаточно — автоматически обычная атака.

После модификаций: если blessed — итоговый урон ×2, если cursed — итоговый урон / 2 (округление вверх).

Использование зелья — если в 4-м слоте экипировки героя есть предмет типа Potion, перед атакой спросить: выпить зелье? Если да — восстановить healAmount HP и manaAmount MP (не превышая maxHp/maxMp), слот экипировки очищается.

Ход врагов — каждый живой враг атакует одного героя (индекс выбирает пользователь). Урон = enemy.damage минус защита от надетой брони (если есть), но не менее 1.

Вывод состояния — кто жив, кто мёртв, текущее HP/MP, активные эффекты.

Битва продолжается, пока все враги или все герои не повержены. После — вывод результата.

6. Сводка по отряду
Количество героев, суммарный уровень, суммарное HP, суммарное MP.

Список героев с экипировкой и статусами.

Состояние инвентаря: занято слотов, суммарная стоимость и вес.

Список врагов.

Технические требования
Перечисления — все enum реализованы и используются.

Структуры — Item, Hero, Enemy и структуры характеристик реализованы.

Битовые поля — StatusFlags используется в Hero, чтение и вывод активных эффектов.

Объединение — ItemProperties хранит характеристики, выбор поля через switch по ItemType.

Указатели и new/delete:

Hero::equipment — new Item[4] при создании героя, delete[] при удалении.

Массив врагов — new[]/delete[] с ручным расширением и сжатием.

Утечек памяти быть не должно: при удалении героя — освободить экипировку; при выходе из программы — освободить массив врагов и экипировку всех героев.

vector — для отряда героев.

array — для инвентаря (16 слотов).

C-строки и string — std::string для имён; хотя бы в одном месте продемонстрировать C-строку (char[]) с последующим созданием string (например, при вводе имени врага).

Весь код в main() — функции не требуются. Если хочется вынести пару вспомогательных — можно, но не обязательно.

Подсказки
Начните с типов данных — опишите все enum, struct, union и битовые поля до main(). Это фундамент.

Меню — через цикл while с switch внутри main(). Подменю — вложенные switch или дополнительные while-циклы.

Для вывода перечислений строкой — используйте switch прямо в cout или серию if/else.

Назначение статусного эффекта при создании героя — после выбора эффекта (0–3) установите соответствующее битовое поле через switch:

Способности за ману — перед атакой спросите пользователя «Использовать способность? (1 — да, 0 — нет)». Проверьте hero.mp >= стоимость. Если да — вычтите MP и модифицируйте урон. Для Healer цель — не враг, а союзник: попросите индекс героя в отряде.

Динамический массив врагов — заведите Enemy* enemies = nullptr и int enemyCount = 0. При добавлении: newSize = enemyCount + 1, newArr = new Enemy[newSize], копирование, delete[] enemies, enemies = newArr, enemyCount++.

Битовые поля читаются как обычные поля: if (hero.status.blessed) { ... }.

Симуляция битвы — самая объёмная часть. Разбейте логику хода на последовательные блоки внутри main() (через комментарии-заголовки), а не на функции.

Проверяйте границы — перед обращением к элементу vector или массива всегда проверяйте, что индекс в диапазоне.
